## 实施阶段与验收

### 阶段一：验证播放可行性 ✅ 完成

在 Windows 上选取普通视频和多分 P 内容，验证元信息、媒体地址、独立音频及进度定位。视频播放与切换验证已移至阶段四。

验收重点：独立音频是否可用、实际传输资源及 WebView 编解码兼容性；已据此确定 HTMLAudioElement 与本地代理方案。

实测结论：独立音频流匿名可用（DASH 三档 AAC），WebView2 播放 fMP4/AAC 正常；WAF 按请求形态拦截（详见 [M0 技术验证记录](m0-findings.md) §2.1）；签名媒体地址有效期很短，"每次播放前重新解析"成为既定架构。音视频切换尚未验证。

### 阶段二：完成最小播放器 ✅ 完成

实现链接添加、分 P / 合集选择、播放队列、基础控制、循环模式和本地恢复。

验收重点：从添加内容到完整音频播放的路径可用；切歌、暂停、定位和重启恢复行为正确。

音频路径已实机跑通（含多分 P 与合集），本地持久化（队列 / 进度 / 音量 / 模式）已就绪；音视频切换按 2026-09-18 调整移至阶段四（账号登录已随 v0.4.0 实现）。

### 阶段三：完善持久化与异常处理 🔶 进行中

增加设置和播放记录保存、媒体地址刷新、网络错误处理和内容失效提示。

验收重点：重启可恢复记录；断网或地址过期不会使应用卡死；失效内容可以重试、移除或跳过。

快照 v3、坏档备份与旧版恢复、失败音源重试、会话隔离、暂停意图、预取回退、代理异常处理、最近播放及封面缩略图内存优化已实现并完成针对性复审；设置页与自动更新已随 v0.3.0 交付，当前版本的完整实机异常矩阵仍未完成。

### 阶段四：扩展平台与体验 🔶 部分提前完成

本地音乐库、喜欢和歌单已提前完成；账号登录与收藏双向同步随 v0.4.0 实现，系统媒体控制随 v0.3.2 实现；macOS 基础音频流程已有历史实机记录。音视频切换、Linux 与移动端适配仍未实现；视频访问范围需按登录状态和内容权限验证。

验收重点：按平台检查格式支持、后台行为、资源占用和打包结果，不以单个平台的成功替代跨平台验证。

## 当前进度

截至 2026-09-24，版本基线为 **v0.4.0**（扫码登录与收藏双向同步随该版本发布；package.json / Cargo.toml / Tauri 配置一致）。此处描述仓库实现进度；远程 Release 与安装包状态以 [Releases](https://github.com/roy2651/bMuisc/releases) 为准。

桌面端已实现：

- **内容添加**：粘贴链接或 BV 号 → 解析元信息（标题 / UP 主 / 封面 / 时长）；多分 P 与合集（ugc_season）双 Tab 选择，支持全选 / 清空，合集条目带各自封面、时长、UP 主。
- **音频播放**：DASH 独立音轨，按码率自动选档；经本地代理拉流（注册表模式：只转发解析登记过的地址；官方 CDN 镜像优先、失败自动轮替；开放式 Range 切成有界分块）。61 分钟长视频实网压测通过：深定位（20%~99% 往返）、候选轮替、连续拉流至片尾均无错误（2026-09-20）。
- **播放控制**：播放 / 暂停、上一首 / 下一首、拖动进度、音量（含百分比显示）、顺序 / 单曲循环 / 列表循环 / 随机四种模式。
- **队列管理**：当前项标记（跳动条动画）、点击播放、移除、清空、上移 / 下移。
- **持久化**：`localStorage` 快照 `bmuisc.snapshot.v3` 保存库、喜欢、歌单、队列与续播状态，兼容 v1 / v2；坏档备份后尝试恢复旧版或重建。进度类每 2 秒节流，关键动作立即保存；重启后由用户触发续播。
- **界面**：深色主题（B 站粉 + 紫渐变强调色），BM 应用图标；顶栏品牌区 + 正在播放大卡片改版，播放频谱波浪（真实 FFT，失败自动降级合成波浪）。
- **测试**：Rust 解析链路实网冒烟测试（`cargo test --test live_parse`，依赖外网）。
- **macOS 适配**：Apple Silicon（M4 / macOS 27）实机验证通过——解析、本地代理拉流、播放、持久化恢复均正常（2026-09-18）。关窗即隐藏窗口（后台继续播放），Dock 点击唤回，Dock 右键 / Cmd+Q 才退出。v0.1.5 补齐 WebKit 细节：SF Pro / 苹方字体栈、禁滚动橡皮筋、文字渲染调优、封面禁原生拖拽、解析弹窗 Esc 关闭。
- **秒切下一首**：开播后按循环模式预解析并预缓冲下一首，命中预取时切歌毫秒级出声（单曲循环同曲重播零解析直接定位）；预取超时或未命中自动回退常规解析，加载状态有明确提示。
- **曲目库与歌单**：全部音乐、我的喜欢、自建歌单的创建 / 重命名 / 删除与曲目管理；解析弹窗可选音乐库 / 喜欢 / 已有或新建歌单，并可勾选立即播放。保存与播放分离；快照只保存元信息、引用及状态，不落媒体文件。
- **稳定性修复**：进度保存、坏档恢复、旧媒体事件隔离、失败后的主播放按钮重试、解析期间暂停、预取失败回退与资源释放、代理 5xx 候选切换和后缀 Range、元信息刷新、窄窗导航及键盘操作入口。

**验证进度**：`3bdbc0d` 对应复审完成 18 项正向隔离探针、前端构建和 Rust 离线输入测试，详见 [复审报告](reviews/2026-09-21-r123-verified.md)。随后 `853d1ed` 补充终败时暂停旧源、无源解析窗口连续点击时保留续播点；本次仅核对实现与文档，未把前轮测试结果当作该提交的新验收。v0.2.0 的桌面实机播放、窄窗 / 键盘与跨平台完整验收仍需补齐。

- **最近播放**：真正开始播放才记录，按最后开播去重置顶，最多 50 条；移除不影响音乐库、喜欢、歌单或队列。同会话暂停恢复 / 错误重试不撤销移除，新的主动点播可重新记入。快照 v3 增量保存，旧档恢复为空列表。14 项正向隔离回归及前端构建通过，另完成 Edge 同源重新定位的媒体事件验证，见 [最近播放复审验收](reviews/2026-09-21-recent-verified.md)。
- **封面缩略图**：列表、队列、播放条、弹窗与正在播放页的全部封面槽位按展示尺寸请求 B 站图片服务的服务端缩略图（方形槽位用方形 `_1c` webp 裁切，形状与槽位一致避免二次裁切；模糊背景用 16:9），行封面解码内存从原图 ~3MB 降到 ~0.26MB，长列表滑动时 GPU 内存峰值从 GB 级回落到百 MB 级。数据与快照仍存原图 URL，缩略图加载失败自动回退原图，动图封面在正在播放大卡片保留动画。

- **账号登录与收藏同步**：B 站扫码登录，SESSDATA 等凭证只进 OS 安全钥匙串（keyring），前端不接触、日志不记录；顶栏账号菜单管理登录态。收藏夹「从B站导入」按收藏夹建歌单、增量去重、失效条目跳过并汇报；「推送到B站」按 bvid 去重、幂等追加，不删除或改动 B 站已有内容。歌单与收藏夹的关联可随推送换绑、随导入更新，建立来源（导入 / 推送）记录后不变；B 站侧数据只增不改删，不调用删除类接口。详见 [账号与收藏同步调研](login-fav-research.md)。
