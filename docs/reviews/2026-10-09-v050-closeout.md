## 后续修复：macOS 构建中的透明窗口 API（2026-10-09）

用户提供的 x86_64-apple-darwin 构建日志显示，mini.rs 调用 transparent(true) 时发生 E0599。已核对锁定版本 Tauri 2.11.5：该方法在 macOS 上受 macos-private-api feature 控制，项目没有启用该 feature。即使界面入口和预建逻辑仅在 Windows 开放，共用模块仍参与 macOS 编译；这一条件同样影响 Apple Silicon 目标。

修复在 [mini.rs](../../src-tauri/src/mini.rs) 中拆分窗口构造，将 transparent(true) 调用放入 cfg(windows) 分支。Windows 保持透明浮窗；macOS 编译不再引用该方法，迷你播放器入口仍待该平台专项验证后开放。

本轮 Windows 的 cargo check --manifest-path src-tauri/Cargo.toml --locked --offline、单文件 rustfmt 检查及 git diff --check 通过。当前机器仅安装 Windows Rust 目标，macOS Intel / Apple Silicon 的完整构建仍需由 CI 确认。本节修改发生在前述 OCR 快照之后，未将此前审查结论当作本轮新审查结果。
